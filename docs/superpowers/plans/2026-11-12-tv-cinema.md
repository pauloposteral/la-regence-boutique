# La Régence TV Evolution Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish the approved cinematic and operational player improvements while preserving the live playlist.

**Architecture:** Extend the existing two-deck React player, keep playback policy in focused pure helpers, and persist additive per-item metadata. Add secure paired-screen observation and a deliberately bounded native-media offline layer. Use the established Lovable editing workflow; review committed diffs before publication.

**Tech Stack:** React/TypeScript, Vite, Vitest/Testing Library, Supabase Postgres/RLS, browser media APIs and service worker.

**Spec:** spec.md, copied with this plan to docs/superpowers/specs/2026-11-12-tv-cinema.md in the repository.

## Global Constraints

Apply every Global constraint in spec.md verbatim. Preserve all existing playlist rows, active/paused states, ordering and files. Root alone performs production deployment after verification.

## Review Focus

- A prepared next source changes while the current transition is underway: never mount a third decoder or reveal a stale source.
- A failed source is aliased by another row or an unrelated playlist edit occurs: cooldown and cycle identity remain correct.
- QR/text-protected media and reduced motion: no scaling/cropping/light interference; transition timing and cleanup agree.
- An anonymous attacker sends heartbeat data: cannot write arbitrary screen records or read telemetry; paired tokens can be revoked.
- Network failure, partial HTTP range, quota exhaustion, or online empty playlist: offline support stays bounded and does not resurrect removed media.
